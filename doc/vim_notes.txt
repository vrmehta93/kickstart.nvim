Search and replace
f/F - forwards/backwards character search on a line. Cursor is on the character
	;/, - go forward/backwards in search
t/T - forwards/backwards character search on a line with cursor before/after the character (depending if you're going backwards or forwards)
Substitute command - :[range]s[ubstitute]/{search pattern}/{replacement string}/[flags] [count]
	range - e.g. %
		- "%" means for the whole file. Replace with "#,#" for line numbers in file
		- OR visually select text and run : and it will show up as :'<,'>
		- If you can run this in visual mode, it only affects selected lines
		- Default range is current line (i.e. ".")
	search pattern - string or regex, including atoms
	replacement string
		\= - execute an actual function
			e.g. :%s/\v(\d+)/\=reverse(submatch(0)) - reverse the order of the digits
				submatch - refers to capture group
	flags:
		- without any flags - first occurence
		- with only "/g" - all occurences within specified range
		- with only "/c" - ask for confirmation each time
	Post running substitute command
		- g& - redo your substitution to entire file
	To do consecutive substitutions, use pipe '|'
		e.g. %s/... |  %s/...
:s - repeat the last substitution command with the last used pattern and replacement string
& - repeat last subtitute command

Regex
	Character classes
		'[bp]le' matches 'ble' or 'ple'
	Anchors
		'^apple' - matches lines starting with 'apple'
		'pie\$' - matches lines that end with 'pie'
	Quantifiers and Atoms (common ones)
		{n} - atoms can be counted
			e.g. {4,} - 4 or more
		'.' - matches any single character
		'.*' - matches zero or more of any character
		'.+' - matches one or more of any character
		'()' - capture group
		'\w' - matches any word character
		'\d' - digits
		'\s' - whitespace
		'\S' - everything that's not a whitespace
		'\v' - very magic mode
		'\r' - newline
	Capture groups
		:s/\old/&-append-something - append '-append-something' to search string
		:s/"\(.*\)"/\1 - removing surrounding "" from string
		:s/\v(\d+)-(\d+)/\2-\1 - swap positions of 2 number groups around '-'
	Advanced
		\zs - pattern to find position but only include what comes AFTER match
		\ze - pattern to find position but only include what comes BEFORE match
		e.g :s/\vstart\zs.*\zeend/replace - replace text between 'start' and 'end' i.e. replace without including search words
	Visual selection
		Typically when you visually select and type ":", it runs the search on the lines
		If you want to restrict search to visually selected (when not line-wise), use \%V

Other helpful notes not included already in kickstarter's init.lua or Tutor
:lua <lua code to execute> - To run lua code
In normal mode
	ZZ - save and quit. Equivalent to :wq
	ZQ - quit without writing. Equivalent of :q!
To run a command in normal mode - :normal <commands> OR :norm
	e.g. :normal iHello or :norm iHello
	e.g. :%norm! f x - On all lines, find " " and delete that character
		"!" in "norm!" - it's possible that you have a lot of customizations that override commands like 'f'. So when you use "!", you're telling vim to interpret that as normal/regular vim keys i.e. use traditional 'f'
<c-x><c-f> - autocomplete filename
:set spell spelllang=en_us - Enable spell check
	z= - Place cursor underneath the highlighted word to see suggestions to fix
	zg - Add word to dictionary
Arguments list:
	:next or :n
	:previous or :prev
	:first/:last
	:args <file1> <file2> ... - set argument list
	:argdo <command> - execute <command> on all files in argument list
To compare 2 files:
	open vim/neovim with -d flag. e.g. vim -d file1 file2
	If already inside vim/neovim, ":windo diffthis"
To encrypt a file in vim, open file, make your edits and run :X
	That will prompt you to enter an encryption key
	To remove encryption, open the file and run :X again. If new encryption key is empty, it will unencrypt
Sessions - save your open buffers so that you can re-open them again after exiting vim
	To create - :mksession <session_name>
	To load session in vim - :source <session_name>
Vim's "find" command
	Append "**" to vim's "path" var (e.g. set path+=**) to allow recursive searching
	Open vim in project root dir so that "find" command to find your files
